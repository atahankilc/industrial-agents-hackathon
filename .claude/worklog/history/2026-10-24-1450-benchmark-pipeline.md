## Summary
Adds `core/solvers.py`, one deterministic solver per benchmark kind behind `solve(bmap, kind, params)`, which takes
the params produced by `core/question_parser.py`. `tests/test_solvers.py` checks them against every train+dev answer,
both on the gold `inputs` and through question text → parser → solver. Docs and memory bank record the empirically
settled rules; a root README documents setup and how to run the archived kit.
`agent/answer.py` turns solver results into replies with a deterministic `Answer:` line (official scorer: dev
138/138); `agent/run_benchmark.py` is the one-command run documented in `BENCHMARK.md`, used to generate the test
submission in `submissions/`. The memory bank also records the first live LLM-parser measurement.
