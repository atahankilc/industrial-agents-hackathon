# Map: buildings fitted onto OSM, all floors on open, map/model in register, see-through shell

- **Author:** Claude (session on branch `map-transition`) · **Date:** 2026-10-25
- **Related:** follow-up to e586454 (map → building transition); user reports: transition missing (macOS Reduce
  motion on), open with all floors, models not matching the map's building shapes, model and map moving apart, the
  map's block of the open building too prominent.

## Summary
Refits each kit building onto its OSM way (new `scripts/fit_locations.py`), opens buildings with all floors stacked,
plays the transition with "reduce motion" on, keeps the map in register with the model (1° field of view enforced on
every follow, model tilt ≤ 60° over the map, per-map fly state for React's dev double mount), and draws the open
building's map blocks as a see-through shell.
